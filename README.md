# Kişisel Web Sitesi Projesi

Bu proje Sakarya Üniversitesi Web Teknolojileri dersi kapsamında geliştirilmiştir.

## İçerik

Projede aşağıdaki sayfalar bulunmaktadır:

- Hakkımda
- Özgeçmiş
- Şehrim
- Takımımız 
- İlgi Alanlarım
- İletişim Formu
- Login Sistemi

## Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript
- Vue.js
- PHP

## Özellikler

- Responsive tasarım
- JavaScript ve Vue.js ile form doğrulama
- PHP ile form verilerinin işlenmesi
- PHP tabanlı login sistemi
- API kullanımı (TMDB ve OpenLibrary)
